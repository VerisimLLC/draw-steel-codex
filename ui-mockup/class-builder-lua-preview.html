What the Lua toolkit changes from the web prototype

Same

Sentences with words you click

One gui.Label per sentence with links = true; each word is a <link=id> region, so the sentence wraps like text. A press reads element.linkHovered and opens the picker as element.popup. The ability roll text already does this.

Changes

Words are marked with a fill

A word you can click gets a <mark> fill (a darker inset of the block's colour) and an underline, and turns white on hover. That works on every block colour, where a link colour would not.

Changes

Block colours are fixed

A block's colour tells the author what kind of block it is, so it is not a theme token. The colours live in one Lua table (BEStyles.BlockColors) as literal hex, set on each block's own style, and each block carries its own white text. A theme recolours the ground, cards, menus and shelf around them. Try the "Warm Gold theme" switch.

Same

Drop slivers

The engine adds drag-target to every valid target during a drag and drag-target-hover to the one under the cursor. That is the style guide's own rule: 2px and clear at rest, a 10px accent bar on hover.

Changes

Dragging from the shelf needs a ghost

A dragged panel moves itself, so a shelf row uses dragMove = false and moves a floating copy in its dragging event (engine ask E2 would make this built in). Every drag keeps a menu path: "Add a block" and the block menu's Move up / Move down.

Changes

Rectangles only

No notched puzzle shapes: panels have per-corner radius, bevels or 9-slice images. Blocks are rows with 5px corners, wrappers indent with a 2px rule, and the combine bracket is three 1px panels plus a button.

Same

Menus and pickers

gui.ContextMenu for short lists, like the gain event menu with "Build the trigger yourself..." at the end; gui.Dropdown with hasSearch for long ones (abilities, conditions); gui.Multiselect chips for skill groups.

Watch

Panel count

Each block is a few panels, but a full class is hundreds. Rebuild only the block that changed, never the stack; use hideObjectsOutOfScroll in the detail column; check long link sentences at 80% to 140% font size.
