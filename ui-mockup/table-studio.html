What this shows

The Table Studio editing "Molten Rift", a copy of Zodiakol (Obsidian). The table behind it is the real Obsidian table from bake-obsidian.ps1 -Preview, with the Draw Steel or the DMHub logo.

  • Peek and Compare act while held. Compare shows the last save (here: before your slider changes).
  • Play Now is dimmed: Obsidian has no timed effect. It is live on Gold Marble, Brushed Steel and Spectral Fog.
  • Type no longer changes after New.
  • Stone's upload arrow shows the loading state; Heat's shows the format warning.
  • The tick on each slider is the starting table's value; right-click a slider row to reset it.
  • Phase 1b: the version dropdown carries a status per version; picking the live one shows the read-only note. Set Live names the access change.
  • Phase 1c: own logo slots and Logo Size.
