# History rules review: Censor, Conduit, Elementalist, Fury, Null

Audit date 2026-11-04. Scope: class features, Heroic Resource rules, subclass features, and
ability riders that fire on their own (persistence, maintenance, judgment, auras, effects
that end on a threshold, "the first time each round..." gains). Ordinary abilities used as
actions are skipped unless they set up a later automatic event. Code and data were read,
not run; nothing was checked in the app.

**Paths.** `R:n` = `ClaudeBridge/ClaudeRefHeroes.lua` line n (the Heroes book as text).
Data paths are under `data/objectTables/`: `c/` classes, `s/` subclasses, `e/`
characterongoingeffects, `r/` conditionriders, `k/` kits, `a/` adventuretables; `m/` is
`data/monsters/`. The YAML line given is the triggered ability or modifier that does the
work. Lua paths are repo-relative.

**Draft lines** are proposals for sign-off, in COPY.md style (past tense, result first,
names not pronouns, Hero and Stamina capitalised, conditions lower case in sentences).
Example names: Human Censor, Dwarf Conduit, Polder Elementalist, Orc Fury, Human Null.

## How the codex decides what reaches the log

1. **Automatic triggers post no cast card.** `TriggeredAbility.mandatory` defaults to `true`
   (`DMHub Game Rules/TriggeredAbility.lua:967`); `ShowChatMessageOnCast()` returns
   `not self.mandatory` (`:2644`). Heroic Resource gains use the setting id
   `game:heroicresourcetriggers` ("Automated Heroic Resource Gains", default on, `:44-51`),
   a truthy string, so they post no cast card either.
2. **So an automatic event shows only if a behavior posts its own card**, and most only do
   when the content author typed a `chatMessage`:
   - Replenish (resource gain/spend): `ResourceChatMessage` when `chatMessage` is set or the
     behavior names a heroic-resource checklist item (`DMHub Game Rules/AbilityReplenish.lua:717-728`).
   - Damage: `ActivatedAbilityDamageChatMessage` only when `chatMessage` is non-empty
     (`Draw Steel Ability Behaviors/AbilityDamage.lua:55-57`); dice damage also opens a roll.
   - Heal (`DMHub Game Rules/ActivatedAbility.lua:5136`), temporary Stamina
     (`Draw Steel Core Rules/DSTemporaryHitpoints.lua:136`), purge effects
     (`DMHub Game Rules/AbilityPurgeEffects.lua:286`): only with a `chatMessage`.
   - ApplyOngoingEffect, rule-text commands (slides, pushes, conditions, flat damage),
     Destroy, Script, FloatText: never. `RecordTokenMessage` writes into a cast card only
     if one exists (`ActivatedAbility.lua:3173-3180`).
3. **Prompted triggers** (`mandatory: false`) post a cast card when the player accepts;
   outcomes sit in the portrait hover.
4. **Nothing logs an effect ending.** There is no chat type for it. "Until the end of the
   encounter or until you are dying" effects are removed silently by
   `creature:StartOnDying` and `creature:EndCombat` (`Draw Steel Core Rules/MCDMCreature.lua:8119-8135`).
   An effect whose `sustainFormula` stops being true also just disappears.
5. **Unspent Heroic Resource is never "lost" as an event.** The resource has
   `clearOutsideOfCombat: true` (`characterresources/heroic-resource.yaml`); the stored
   value is tied to the combat id and reads as 0 afterwards (`DMHub Game Rules/Resource.lua:48-107`).
6. **Passive numbers fold into rolls.** Edges, banes, damage and potency modifiers appear
   only inside the roll; the roll record keeps the kept modifier names
   (`rollProperties.modifiersUsed`, `Draw Steel UI/DSRollDialog.lua:3963-3976`). Triggered
   options used from the roll dialog pay their cost silently (`DSRollDialog.lua:3864-3881`).

**Logged today codes.** RES = resource line with the quoted reason. DMG = damage line with
the quoted text. TMP = temporary Stamina line. NOTE = `ActionLogNoteChatMessage`. CAST = cast
card (prompted trigger accepted, or ability used). ROLL = only inside a roll. CHIP =
immunity/weakness chip (`DamageModifierChatMessage`). FLOAT = floating text over the token,
not in the log. NO = nothing.

**Row types.** Action = action row. Nested = triggered row under what set it off. Turn line
/ Resource line / Ended line = compact lines with no action. Why = detail-card Why line.
