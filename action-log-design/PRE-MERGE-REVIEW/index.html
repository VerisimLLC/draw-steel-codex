Invoked abilities (James 2026-11-21, after a content scan: 263 actions invoke one that opens its own card): the row is always the outer ability. A Custom Ability invoke is a step of that ability (marked _tmp_partOfAbility on the clone) and joins its row whatever card it shows, so "Invoked Ability" rows are gone and Get In Get Out is one row. A real ability invoked by name, as a standard ability or chosen (Hide, Agonizing Harmony, Throw, Prism's picks) keeps its own row, nested under the action like a triggered action, tagged with its action kind. An untouched user listed as the outer's only target is dropped once steps or nested abilities show. Checked live: Get In Get Out (one row, kit part), a test action invoking Catch Breath (nested), Natural Weapon (one row, one roll, both targets), Prism with two heroic abilities (Prism row with no roll of its own, each ability nested with its own roll).     1. Fix before merge¶

    1. New users never get their built-in View. Checked. HistoryTray.lua:6333 runs PlaceRailButton() synchronously on EnterGame; RailPlaceBelow("history", "chat") writes iconraillayout. DocumentSystem's EnterGame coroutine (DocumentSystem.lua:27224) waits for the documents layer + 5 frames, then finds iconraillayout non-empty, so nothingOfTheirs is false and ViewsSwitchTo("builtin:player"/"builtin:director") never runs. Every first entry to a game (layout is per-game). Crows same via the Action Log. Also: a pristine v6 user's rail no longer matches the stamp, so they get the "updated / Keep mine" prompt instead of a silent update. Fix: skip when the layout is empty (v7/v8 already place History), or run after the View auto-apply.
    2. A History write before the document has synced can wipe that map's History. Checked. History.lua:303 WriteEntries has no doc.isnew / loading gate; on an empty snapshot it seeds tables and CompleteChange PUTs over the cloud doc (the playlist wipe mechanism). Any capture while a client is still loading or rejoining. Fix: requeue while doc.isnew or the game is loading.
    3. Undo on a reverted resource line applies twice. Checked. HistoryTray.lua:2489 ignores entry.reverted. Revert Turn restores the Recovery, then Undo on the faded line takes the heal off and refunds the Recovery again. Same for Turn Rewind. Fix: and entry.reverted == nil.
    4. main's new Action Log Note behavior (f2a2b312) shows nowhere by default. Checked the path. ActionLogNoteChatMessage.Post (AbilityReplenish.lua:213) is a plain chat.SendCustom, which only the old Action Log renders, and it has no play-observer notify. A trigger whose only effect is the note writes no History row (ChangedTheTable, HistoryCapture.lua:412, ignores messages). The older Post callers (AbilityDamage.lua:482 bonus note, MCDMCreature.lua:7558 heal bonus) have the same gap. No data uses log_note yet; Condemned (Gerold) is the intended user.

    2. Privacy: players see Director-only information¶

    1. Hidden / invisible creatures are named to players. History.Creature (HistoryCapture.lua:88) records only namePrivate; ForPlayers (History.lua:449) has no invisibleToPlayers / IsHidden() cut (only reinforcements check it, Capture:2240).
    2. GM-only and Dice Tower table rolls and saves show to players. OnTableRolled (Capture:2142) and OnSaved (Capture:2025) never record RollUtils.RollPrivacy.
    3. Monster Stamina numbers. Checked. staminaset (Capture:2200) and temporarystamina (Capture:1206) store exact values; the tray prints "X Stamina 40 to 25" (HistoryTray.lua:2217) with no Monster Knowledge gate.
    4. Malice lines in the rail badge and hover card. Checked. Unseen() (HistoryTray.lua:5944) runs every line through LineWords with no malice filter (the list and bubble both filter it). Players also get phantom unseen turns from ownerless Malice lines; the Director gets quiet Malice lines.
    5. Monster trigger cards through the ability title. Checked. AbilityCard falls back to TriggerCard (HistoryCard.lua:737); the header (:897) gates only on PlayersMaySeeAbility, which is revealed on any use. Breaks COPY Round 18.
    6. Side view of a token the player can't see. Checked. RowMovers (HistoryCard.lua:1032) tests token.valid, not canSee; the ghost shows its live appearance and path.
    7. Smaller: a hidden roll's total survives in who.opposed (History.lua:526); surge origin hovers (part.freefrom[i].hover, gainedfrom) aren't cleared by WithoutHovers (History.lua:535, card :2843). Malice filtering lives in the tray, not ForPlayers, so any new reader leaks it.

    3. Old Action Log, Crows and dock-mode regressions¶

    1. Applying a built-in View drops the Action Log for old-log and Crows users: ViewsApplyLayout (DocumentSystem.lua:27934) stores v7/v8 as-is (no "action log"), and PlaceRailButton runs only on EnterGame / the setting change. Crows on a pristine v6 view loses it for the session after the silent update.
    2. Dock mode loses a docked Action Log with nothing in its place. PanelPermittedForUser now checks available (DockablePanel.lua:2259); History is never added to a dock. Medium confidence (depends on rail-off users).
    3. Audio captions. They moved from chat to the Chat rail bubble: they fade within about 1.3 s when Chat is in front (the bubble think at DocumentSystem.lua:17386 ignores evenInFront), and show nothing in dock mode, with Chat grouped/overflowed, or on the old log (Audio.lua:1238-1363). The 10 s freshness check compares two clients' server time (skews).
    4. The sidebar preview keeps running for old-log users. Checked. BubbleTick (HistoryTray.lua:6233) gates only on History.Enabled(); it sorts keys for every map every 0.5 s and builds bubble panels that ShowRailBubble then drops unattached. Fix: bail on History.UsingOldLog().
    5. History radial item (TokenUI.lua:2818) and card chip (HeroCardBack.lua:1559) show for old-log users and do nothing; gate on UsingOldLog(). The EotW HUD (EncounterOfTheWeekHud.lua:1220) reads UsingOldLog() once at build.

    4. Robustness: a History error can stall play¶

    1. Tests can hang. Checked. RollCustomPowerTableTest's completeRoll (MCDMCreature.lua:5517) calls NotifyTested before the pcall'd onComplete; the notify's own work (RollUtils.NotifyTested) is outside the observer pcall. A raise there leaves a montage or puzzle test waiting with its card hidden. Same order in ShowCharacteristicRollDialog (:5632, drops "rollpower" triggers) and DSRequestRollsDialog.lua:1104 (the Director's request waits forever). Fix: pcall or move after.
    2. A nil map drops the whole frame's batch. Checked. Flush (History.lua:355) indexes byMap[entry.map] outside the pcall after clearing g_waiting. Possible for off-map heroes (respites through GetCharacterById).
    3. HandEdit, ForCast, EndingEffects (Creature.lua:80, :98, :9105) pcall and re-raise with error(err, 0): every RemoveOngoingEffect, purge, end-of-turn removal and TacPanel hand edit now loses its stack trace in bug reports. Use xpcall(fn, debug.traceback).
    4. Roll details (AddRoll, AddDamageParts, AddRollTriggers, EdgeSources, Capture:792-833) run before History.Write; one error silently loses the row. The up-front spend's 0.5 s Schedule (Capture:1450) doesn't check token.valid.

    5. Wrong or stale display¶

    1. Merged "ended" lines never show Reverted (HistoryTray.lua:3668): the sig omits reverted; the rebuild also drops hidden/secret (HiddenEye missing) and appends to the shared sources table, widening the Director's Delete/Hide.
    2. Action row sig ignores nested-entry rewrites (HistoryTray.lua:3685): Hide/Reveal on a nested trigger or roll doesn't rebuild the row or open card; the menu keeps offering "Hide from players"; a revealed secret opposed roll stays "rolled in secret". Fix: tostring(kid) in the sig.
    3. Per-target roll data by loop index (MCDMAbilityRollBehavior.lua:2415-2460): with promptWhenResolving, every target reads multitargets[1]'s edges, banes, sources and surges. The in-play surge count has had the same bug since before the branch. main's b64b3c71 narrows it to forced-movement tiers. Match by tokenid.
    4. Lines filed under game.currentMapId (Malice with no caster Capture:1541, Hero Tokens 1568, downtime 1613, negotiation 1662, montage 1722, OnTurnReverted 2320): a Director looking at another map files them there, and Revert Turn marks nothing on the combat map.
    5. Turn Rewind still matches by time (History.lua:754, :775), the skew Revert Turn already fixed.
    6. OnTurnEnded (Capture:2365) runs ModifyProperties on every token with lapsed effects from inside History, on whichever client clicked End Turn, once per token in a group turn: game state that only changes when History is on.
    7. Card scroll maxHeight = args.maxHeight - 62 (HistoryCard.lua:3675) assumes a one-line header; a wrapped title runs the bottom past the frame.
    8. The fold-animation copy (HistoryTray.lua:5574) isn't MakeNonInteractiveRecursive: a map click in its 0.9 s flight can land on the copy.
